# MedRemind-AI-
AI-powered healthcare app with medicine reminders, diet planner, doctor consultation, mental health tests, and Gemini AI assistant( working in process).
MedRemind is an AI-powered smart healthcare assistance web application designed to help users manage their daily health activities efficiently. The platform provides medicine reminders with voice alerts, doctor consultation scheduling, disease and diet planning, prescription management, psychological health testing, and AI-powered healthcare assistance. Users can interact with the AI assistant through text and voice input for instant support and guidance. The application also includes online doctor consultation options such as chat, voice call, and video call simulation with multiple healthcare specialists including physicians, cardiologists, psychologists, dermatologists, and neurologists. MedRemind features a clean healthcare-focused UI built using HTML, CSS, JavaScript, Node.js. The project aims to improve healthcare accessibility, medicine adherence, and mental wellness support through smart technology and user-friendly design. This application is ideal for healthcare hackathons, beginner full-stack projects, and AI-based healthcare innovation demonstrations.
